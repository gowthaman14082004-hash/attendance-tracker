# Contributing to Attendance Tracker

Thank you for your interest in contributing! 🎉

## How to Report a Bug

1. Check [existing issues](https://github.com/gowthaman14082004-hash/attendance-tracker/issues) to avoid duplicates.
2. Open a new issue with:
   - A clear title and description
   - Steps to reproduce
   - Expected vs actual behaviour
   - Your OS, Python version, and Flask version

## How to Submit a Pull Request

1. Fork the repository
2. Create a feature branch: `git checkout -b feat/your-feature`
3. Make your changes with clear commit messages
4. Test your changes: `flask run`
5. Push to your fork: `git push origin feat/your-feature`
6. Open a Pull Request with a clear description

## Coding Standards

- Follow [PEP 8](https://pep8.org/) for Python code
- Use type hints where practical
- Add docstrings to new functions and classes
- Keep HTML templates clean and accessible
- Test all routes after changes

## Commit Message Format

```
feat: add CSV export for attendance reports
fix: correct 12-hour time format for midnight
docs: update README deployment guide
style: improve mobile nav responsiveness
```
